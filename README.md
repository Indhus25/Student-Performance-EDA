# Student Performance EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Student Performance Factors dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset structure and shape
- Data types and memory usage
- Missing value analysis
- Summary statistics
- Categorical analysis
- Five data visualizations
- Key findings and conclusions

## Key Finding
Study hours and exam scores show a moderate positive correlation of 0.45.

## Dataset
Student Performance Factors Dataset from Kaggle.
